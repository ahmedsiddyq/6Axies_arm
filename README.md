# 6-Axis Robotic Arm

Development of a six-axis robotic arm and its motion-control system.

## Overview
This project combines mechanical motion, embedded control, stepper/servo systems, position feedback, and robot kinematics.

## Focus
- 6-axis motion control
- Stepper/servo control
- Coordinate systems and kinematics
- Position control
- Embedded machine control

## Status
Development project. Mechanical and firmware implementations may evolve during testing.
